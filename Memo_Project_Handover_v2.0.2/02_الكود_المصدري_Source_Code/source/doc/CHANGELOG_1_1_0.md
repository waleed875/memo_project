# سجل 1.1.0 — قسم التقارير واللوحة المركزية + تقرير الشركة ويب

## الجديد

- **قسم التقارير واللوحة المركزية** (`?view=central`): أربع تابات بنفس الشريط
  الموحد — المدير العام (جدول الشركات + أعلى/أدنى 5 جودة والتزام + إجمالي
  شهري، قراءة فقط)، مدير البرنامج (معتمدة/بانتظار/معادة + الالتزام + متوسط/
  أقصى تأخير + تكرار + أخطاء البنود العشرة، بفلاتر الفترة والأساس)، الشركات
  (ملخص + مقارنة فترة سابقة + رابط التقرير المخصص)، المراجعة (طابور التدقيق
  من `core.notes` مباشرة + انتقال لتقرير الشركة). التابات ظاهرة للجميع.
- **نقطة طابور المراجعة** `GET /api/dashboard/review-queue` (حالات
  `NEEDS_REVIEW/UNDER_REVIEW` فقط + ترقيم صفحات).
- **تقرير الشركة ويب**: نفس فلاتر `FilterQuery` ونطاق V3 (شركة + فترة +
  أساس + قطع) + حقول `Issue` السبعة (يبنيها المستخدم) + `FilterSummary`
  تلقائي + تذييل (كتاب/محرر/تاريخ) + طباعة أفقية + `PDF خادمي` (Chromium بلا
  أي كلفة ترخيص) + `Excel` بورقة RTL + معاينة HTML.
- **نقطة الأشهر** `GET /api/dashboard/company-monthly` (افتراضيًا آخر 6 أشهر).
- **الشارتات الثلاثة القانونية** داخل تاب الشركات: خط الجودة + أعمدة الحجم،
  دونات الفئات الأربع، أعمدة التأخير — بقواعد `rtl/tooltip/x.reverse` وحاويات
  `dir="rtl"`، وأرقام `tabular-nums`.
- **تصميم**: ثوابت الهوية محفوظة (`--brand-gold/brown` + خط Qomra)، `Header`
  موحد، `dir` من اللغة للعناوين الرسمية، `:lang(ar)` بلا `letter-spacing`.

## قرارات المالك المنفذة

- `review-queue` من `core.notes` مباشرة (لا `ReportService`).
- PDF خادمي عبر Chromium (استُبعد QuestPDF: رخصته المجانية تستثني الحكومات).
- التابات ظاهرة للجميع؛ ملفات `Modern/V3` الميتة باقية؛ مسودة `066` مؤجلة
  (لا ترحيل في 1.1.0 — البقاء على `065`).
- الإصدارات: خلفي `1.1.0`، واجهة `1.5.0` (استمرار `1.4.0`).

  بدل رفضه؛ كل أخطاء الطلب في التقرير `ArgumentException` (400) وغياب
  الإعداد وحده `503` — بلا رموز ولا فروع معقدة.
