# سجل 1.0.7 — ما تغيّر عن 1.0.6

## إصلاحات (L2 → L10)

- **التاريخ (L4)**: أساس صريح كتابة/وصول + قطع وصول مستقل في التقارير
  والداشبورد (مكتبي وويب) والتصدير؛ اليوم التشغيلي دمشق.
- **التكرار (L5/L7)**: مفتاح (شركة + نوع + سنة الكتابة + رقم) مع قفل يشمل
  السنة؛ تصدير الحوادث سطر لكل حادثة؛ بطاقات حوادث/متأثرة منفصلة.
- **المصادر (L6)**: نموذج مصدر حصري (إخراج متعدد/فواتير/غنائم/آخر) + توافق
  `v_note_links_compat`؛ المرشحون لا يُخفون المرتبط.
- **المدير (L2)**: تعديل إداري يحفظ الحالة والمسار + تزامن متفائل + تدقيق فرق.
- **الواجهات (L3)**: عرض ملاحظة المدخل وسبب الإعادة، حماية `PopulateColumns`.
- **الشبكة (L8)**: عنوانا لوحة/تحديث منفصلان، `InternalLanHttp` صريح، فصل
  التحديث runtime، وثيقة جدار الحماية.
- **المؤشرات (جديد)**: نسبة التكرار، آليات غير المربوطة، الالتزام المرجح،
  المركّب — في تقرير DevExpress وصفحة ويب `?report=company`.
- **قاعدة البيانات**: ترحيلات `062` (رقمية)، `063` (مصادر)، `064` (أساس
  الداشبورد)، `065` (توافق `1.0.7` فقط).
- **الحل**: إصلاح GUID مجلد `Compatibility` في `.sln`؛ لغات الأقمار محصورة
  (`ar;en`).
