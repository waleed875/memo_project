# حزمة تسليم المشروع الرسمية — منظومة إدارة المذكرات والرقابة الصناعية (MemoDashboard 2.0.2 / 2.1)

<div dir="rtl">

مرحباً بك في الحزمة الرسمية المجهزة لتسليم مشروع **منظومة إدارة المذكرات والرقابة والتفتيش الصناعي (MemoDashboard)** إلى الجهة المستلمة وفريق التطوير والعمليات (DevOps / Operations / Developers).

## ⚡ التشغيل السريع في دقيقة واحدة (Quick Start)

### على خوادم أوبونتو لينكس (Ubuntu Server):
```bash
# 1. فك ضغط حزمة لينكس
unzip MemoDashboard-2.0.2-linux-x64.zip -d /tmp/memo-install
cd /tmp/memo-install

# 2. تشغيل سكربت التثبيت التلقائي (أوفلاين بدون إنترنت)
sudo ./install.sh --port 8080 --bind-address 0.0.0.0 --allowed-hosts "*"
```

### على أجهزة وسيرفرات ويندوز (Windows):
1. افتح المجلد: `01_حزم_التثبيت_والتشغيل_Install_Packages\MemoDashboard-2.0.2-win-x64`
2. انقر نقراً مزدوجاً على الملف: **`تشغيل_النظام.cmd`**
3. سيفتح النظام في المتصفح تلقائياً على الرابط: `http://localhost:5000`
   * **اسم المستخدم:** `admin`
   * **كلمة المرور:** `098`
