# دليل التنصيب والتشغيل الشامل — منظومة إدارة المذكرات والرقابة الصناعية (MemoDashboard 2.0.2)

<div dir="rtl">

مرحباً بك في دليل التثبيت والتشغيل الرسمي لمنظومة **MemoDashboard (الإصدار 2.0.2)**.  
صُممت هذه الحزمة لتكون **مكتفية ذاتياً بنسبة 100% (Self-Contained & Offline-Ready)**، بحيث يمكن تثبيتها وتشغيلها في بيئات الإنتاج المعزولة تماماً عن شبكة الإنترنت دون الحاجة لتنزيل أي حزم أو أدوات خارجية.

---

## 1. المتطلبات العامة للنظام (System Prerequisites)

### أ. المواصفات العتادية الموصى بها (Recommended Hardware)
* **المعالج (CPU):** 2 vCPU فأعلى (معمارية x86_64).
* **الذاكرة العشوائية (RAM):** 4 جيجابايت كحد أدنى (يوصى بـ 8 جيجابايت في بيئات الإنتاج ذات الضغط العالي).
* **مساحة التخزين (Storage):** 20 جيجابايت مساحة شاغرة (لتخزين قاعدة البيانات والمرفقات والنسخ الاحتياطية).
* **الشبكة:** منفذ شبكة LAN بسرعة 100/1000 ميجابت/ث.

### ب. متطلبات نظام التشغيل (Supported Operating Systems)
* **Linux:** Ubuntu Server 20.04 LTS / 22.04 LTS / 24.04 LTS (x64).
* **Windows:** Windows 10 / 11 / Windows Server 2016 / 2019 / 2022 (x64).

### ج. قاعدة البيانات (Database)
* **PostgreSQL:** الإصدار 14 أو 15 أو 16 (محلياً على نفس الخادم أو عبر سيرفر منفصل في الشبكة الداخلية).

> [!NOTE]
> لا يُشترط تثبيت أي إصدار من .NET Runtime أو SDK على أجهزة الخوادم؛ فالحزمة تأتي مدمجة ومغلقة بمحرك وقت التشغيل الداخلي (.NET 8 Runtime Embedded) ونواة CLR المستقلة بالكامل.

## 2. محتويات مجلد حزم التثبيت (`01_حزم_التثبيت_والتشغيل_Install_Packages`)

تحتوي الحزمة المجهزة على الملفات التالية:
1. **`MemoDashboard-2.0.2-linux-x64.zip`**: حزمة الخادم الكاملة لنظام لينكس أوبونتو (تحتوي على الباك إند التنفيذي، ملفات `runtimeconfig.json` و `deps.json`، محرك وقت التشغيل `libcoreclr.so`، واجهة الويب المبنية في `wwwroot`، الخطوط العربية الرسمية، وترحيلات قاعدة البيانات).
2. **`install.sh`**: سكربت التثبيت والترقية المؤتمت لسيرفرات أوبونتو، مضبوط بصلاحيات نظام التشغيل الصارمة وإدارة خدمة `systemd`.
3. **`MemoDashboard-2.0.2-win-x64.zip`**: حزمة التشغيل المستقلة لأنظمة ويندوز (مضغوطة).
4. **`MemoDashboard-2.0.2-win-x64/`**: مجلد تشغيلي مفكوك وجاهز للتشغيل الفوري بنقرة واحدة على ويندوز عبر ملف `تشغيل_النظام.cmd`.
5. **`database_clean_master_data.sql`**: ملف تفريغ قاعدة البيانات النظيفة بالبيانات الأساسية المعتمدة (الشركات، المعامل، الخطوط، المستخدمين، الصلاحيات، الإعدادات) مع الترحيلات المكتملة حتى الإصدار 070، وخالية تماماً من المذكرات التجريبية.

## 3. التثبيت والتشغيل على سيرفرات لينكس (Ubuntu Linux)

### الخطوة 1: تجهيز قاعدة بيانات PostgreSQL
إذا كانت قاعدة البيانات مثبتة على الخادم أو على سيرفر مجاور، قم بإنشاء قاعدة بيانات فارغة باسم `memodb` ومستخدم باسم `postgres` (أو أي مستخدم تختاره):

```bash
# تسجيل الدخول لمستخدم postgres
sudo -u postgres psql

# إنشاء قاعدة البيانات ومستخدم النظام (مثال)
CREATE DATABASE memodb;
CREATE USER memo_admin WITH ENCRYPTED PASSWORD 'StrongPassword123';
GRANT ALL PRIVILEGES ON DATABASE memodb TO memo_admin;
\q
```

لاستيراد البيانات الأساسية النظيفة المرفقة:
```bash
sudo -u postgres psql -d memodb -f /مسار_الملف/database_clean_master_data.sql
```

### الخطوة 2: نقل الحزمة وفك ضغطها على السيرفر
انسخ ملف الحزمة `MemoDashboard-2.0.2-linux-x64.zip` إلى الخادم (عبر SCP أو SFTP أو فلاشة):

```bash
# إنشاء مجلد مؤقت وفك الضغط
mkdir -p /tmp/memo-pkg
unzip -q MemoDashboard-2.0.2-linux-x64.zip -d /tmp/memo-pkg
cd /tmp/memo-pkg
```

### الخطوة 3: تشغيل سكربت التثبيت التلقائي `install.sh`
قم بتشغيل السكربت بصلاحيات المدير (`root` أو `sudo`):

```bash
# التثبيت بالخيارات الافتراضية (استماع على المنفذ 8080 للشبكة الداخلية)
sudo ./install.sh --port 8080 --bind-address 0.0.0.0 --allowed-hosts "*"
```

#### ما الذي يقوم به السكربت تلقائياً؟
1. **التحقق الذاتي من بيئة التشغيل:** يكتشف محرك .NET 8 المدمج في الحزمة دون الاتصال بالإنترنت.
2. **تسجيل مستخدم النظام الآمن:** ينشئ مستخدم نظام مخصص `memo-dashboard` دون صلاحيات دخول صدفيّة (no-login).
3. **تثبيت ملفات التشغيل:** ينقل البرنامج إلى `/opt/memo-dashboard/releases/<RELEASE_ID>` ويربطها عبر الرابط الرمزي `/opt/memo-dashboard/current`.
4. **توليد مفاتيح الأمان والتوقيع الرقمي:** ينشئ زوج مفاتيح تشفير RSA (3072-bit) تلقائياً في `/etc/memo-dashboard/secrets` مع عزل صلاحيات الوصول.
5. **تسجيل خطوط الطباعة العربية:** يسجل خطوط `ITF Qomra Arabic` في مجلد الخطوط النظامي `/usr/share/fonts/truetype/qomra`.
6. **بناء خدمة systemd وتشغيلها:** ينشئ الملف `/etc/systemd/system/memo-dashboard.service` ويفعله ويعيد تشغيل الخدمة، ثم يتحقق من سلامة فحص الصحة `/api/setup/status`.

### الخطوة 4: إدارة الخدمة في لينكس (Commands)
```bash
# معرفة حالة الخدمة وسجلاتها الحية
sudo systemctl status memo-dashboard

# إعادة تشغيل الخدمة
sudo systemctl restart memo-dashboard

# إيقاف الخدمة
sudo systemctl stop memo-dashboard

# متابعة السجلات المباشرة للتطبيق
sudo journalctl -u memo-dashboard -f --no-pager
```

## 4. التثبيت والتشغيل على أنظمة ويندوز (Windows Desktop / Server)

### التشغيل الفوري المباشر (Quick Start)
1. افتح المجلد المرفق:  
   `01_حزم_التثبيت_والتشغيل_Install_Packages\MemoDashboard-2.0.2-win-x64`
2. انقر نقراً مزدوجاً على الملف:  
   **`تشغيل_النظام.cmd`**
3. سيقوم البرنامج بـ:
   * تشغيل خادم Kestrel الذاتي على المنفذ `5000`.
   * فتح المتصفح الافتراضي تلقائياً على الرابط: `http://localhost:5000`.
   * استخدام بيانات الدخول الافتراضية:  
     * **اسم المستخدم:** `admin`  
     * **كلمة المرور:** `098`

### التثبيت كخدمة دائمة في Windows Server (Background Service)
لتشغيل البرنامج كخدمة خلفية دائمة تعمل حتى بعد تسجيل خروج المستخدم:
1. استخدم أداة **NSSM** (Non-Sucking Service Manager) المجانية والمفتوحة المصدر:
   ```cmd
   nssm install MemoDashboard "D:\MemoDashboard\MemoDashboard.Backend.exe" --urls "http://0.0.0.0:5000"
   nssm set MemoDashboard AppDirectory "D:\MemoDashboard"
   nssm start MemoDashboard
   ```
2. أو من خلال مجدول المهام (Windows Task Scheduler) بمهمة "At system startup" بحساب `SYSTEM` أو حساب خدمة مخصص.

## 5. ضبط إعدادات الاتصال بقاعدة البيانات (Configuration)

### الطريقة الأولى: عبر معالج الإعداد التفاعلي (Web Wizard)
إذا تم تشغيل المنظومة لأول مرة دون وجود ملف إعداد مسبق، ستفتح المنظومة تلقائياً شاشة **معالج إعداد السيرفر**:
1. أدخل بيانات الاتصال بقاعدة البيانات:
   * **عنوان المخدم (Host):** `localhost` أو IP السيرفر (مثال `192.168.1.100`).
   * **المنفذ (Port):** `5432`.
   * **اسم قاعدة البيانات (Database):** `memodb`.
   * **اسم المستخدم (Username):** `postgres` أو المستخدم المخصص.
   * **كلمة المرور (Password):** كلمة مرور قاعدة البيانات.
2. انقر على **"اختبار الاتصال وحفظ الإعدادات"**.
3. ستقوم المنظومة باختبار الاتصال وتطبيق الترحيلات التلقائية وتوجيهك إلى بوابة تسجيل الدخول.

### الطريقة الثانية: عبر ملف الإعداد المباشر (`app_settings.json`)
يمكن وضع ملف الإعداد يدوياً في مسار البيانات الخارجي:
* في **لينكس**: `/var/lib/memo-dashboard/app_settings.json`
* في **ويندوز**: بجوار الملف التنفيذي داخل مجلد `App_Data\app_settings.json`

محتوى الملف النموذجي:
```json
{
  "Host": "localhost",
  "Port": 5432,
  "Database": "memodb",
  "Username": "postgres",
  "EncryptedPassword": "..."
}
```

## 6. استكشاف الأخطاء الشائعة وحلولها (Troubleshooting)

| المشكلة | السبب المحتمل | الحل |
| :--- | :--- | :--- |
| **تعذر الوصول للموقع من جهاز آخر في الشبكة** | جدار الحماية (Firewall) يغلق المنفذ 8080 أو 5000. | في لينكس نفذ: `sudo ufw allow 8080/tcp`. في ويندوز أضف قاعدة في Windows Defender Firewall للسماح بالمنفذ. |
| **رسالة "قاعدة البيانات غير متصلة"** | خدمة PostgreSQL متوقفة أو معلومات كلمة المرور غير صحيحة. | تأكد من عمل بوستجرس: `sudo systemctl status postgresql`، وتأكد من ملف `pg_hba.conf` للسماح بالاتصال. |
| **تقرير PDF يجيب بالخطأ 503** | متصفح Chromium غير متوفر على السيرفر لتوليد PDF. | قم بتثبيت كروميوم عبر: `sudo apt install -y chromium-browser` أو تحديد مسار المتصفح في متغير البيئة `MEMO_CHROMIUM_PATH`. |
| **ظهور خطوط عربية غير منسقة في التقارير** | عدم تسجيل خطوط النظام الرسمية. | نفذ في لينكس: `sudo fc-cache -f -v` للتأكد من تحديث فهرس الخطوط. |
