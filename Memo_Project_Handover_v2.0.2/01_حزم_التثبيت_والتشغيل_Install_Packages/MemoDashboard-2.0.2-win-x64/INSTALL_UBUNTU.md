# دليل التثبيت والنشر الشامل على نظام أوبونتو (Ubuntu) — الإصدار 2.0.2

يوفّر هذا الدليل الخطوات الكاملة والتفصيلية لتثبيت وتشغيل منظومة لوحة البيانات المركزية وإدارة المذكرات **MemoDashboard 2.0.2** على خوادم **Ubuntu Linux** (الإصدارات المدعومة: 20.04 LTS / 22.04 LTS / 24.04 LTS).

---

## 1. المتطلبات الأساسية للنظام (System Requirements)

- **نظام التشغيل**: Ubuntu 20.04 LTS / 22.04 LTS / 24.04 LTS (بنية 64-bit x86_64).
- **المواصفات العتادية الموصى بها**:
  - معالج: 2 vCPU أو أعلى.
  - الذاكرة العشوائية: 4 جيجابايت فما فوق.
  - مساحة التخزين: 20 جيجابايت مساحة متاحة.
- **قاعدة البيانات**: PostgreSQL (الإصدار 14 فما فوق). يمكن أن تكون على نفس الخادم أو على خادم منفصل.
- **بيئة التشغيل**:
  - Microsoft ASP.NET Core Runtime 8.0 (يقوم سكربت `install.sh` بتثبيته وضبطه تلقائياً).
  - متصفح Chromium لتوليد تقارير PDF الخادمية (يقوم `install.sh` بتثبيته وضبطه تلقائياً).
  - خطوط قمرة العربية الرسمية `ITF Qomra Arabic` (مدمجة في الحزمة وتُسجّل في النظام تلقائياً).

---

## 2. محتويات حزمة النشر (`export/`)

تحتوي الحزمة على الملفات التالية:
1. `MemoDashboard-2.0.2-linux-x64.zip`: حزمة التشغيل الجاهزة لنظام لينكس متضمنة الباك إند المبني والواجهة المترجمة والخطوط وسكربتات الترحيل وسكربت `install.sh`.
2. `install.sh`: سكربت التثبيت والترقية التلقائي والمؤتمت لنظام أوبونتو (متوفر كملف مستقل ومدمج أيضاً داخل الحزمة المضغوطة).
3. `database_clean_master_data.sql`: ملف تفريغ قاعدة البيانات النظيفة الجاهزة، متضمنةً كافة البيانات الأساسية (الشركات، المعامل، الخطوط، الحقول، المستخدمين، الصلاحيات، الإعدادات) والترحيلات حتى الإصدار 070، وخالية تماماً من أي مذكرات.
4. `MemoDashboard.Web-2.0.2-source.zip`: الكود المصدري الكامل للمشروع لمن يرغب بإعادة البناء محلياً.

---

## 3. خطوات التثبيت السريع (Quick Installation)

### الخطوة 1: نسخ الحزمة وفك الضغط على السيرفر
انسخ ملف `MemoDashboard-2.0.2-linux-x64.zip` إلى مجلد على السيرفر (مثلاً `/tmp` أو `/root`) ثم قم بفك ضغطه:

```bash
# تثبيت أداة unzip إذا لم تكن متوفرة
sudo apt update && sudo apt install -y unzip

# إنشاء مجلد وفك الضغط
mkdir -p /tmp/memo-install
unzip MemoDashboard-2.0.2-linux-x64.zip -d /tmp/memo-install
cd /tmp/memo-install
```

---

### الخطوة 2: تشغيل سكربت التثبيت المؤتمت (`install.sh`)

قم بإعطاء صلاحية التنفيذ للسكربت ثم شغله بصلاحيات الجذر (`sudo`):

```bash
chmod +x install.sh
sudo ./install.sh --port 8080 --bind-address 0.0.0.0 --allowed-hosts "*"
```

> **ملاحظة هامة حول المعاملات**:
> - `--port 8080`: المنفذ الذي سيعمل عليه التطبيق (يمكن تغييره إلى أي منفذ آخر).
> - `--bind-address 0.0.0.0`: يتيح الاستماع لكافة اتصالات الشبكة المحلية (LAN).
> - `--allowed-hosts "*"`: النطاقات أو العناوين المسموح بها، يمكن كتابة الـ IP المباشر مثل `192.168.1.50;localhost`.
> - `--install-root /opt/memo-dashboard`: مسار التثبيت الافتراضي في النظام.
> - `--service-name memo-dashboard`: اسم الخدمة في مدير الخدمات `systemd`.

يقوم السكربت تلقائياً بالمهام التالية:
1. فحص وتثبيت حزم النظام المطلوبة (`curl`, `unzip`, `openssl`, `libicu`).
2. تثبيت بيئة عمل `.NET 8 Runtime` من مستودعات مايكروسوفت الرسمية إن لم تكن مثبتة.
3. تثبيت وضبط متصفح `Chromium` لتشغيل ميزة تصدير الـ PDF.
4. تثبيت خطوط قمرة العربية `ITF Qomra Arabic` في `/usr/share/fonts/truetype/qomra` وتحديث كاش الخطوط للنظام.
5. إنشاء مستخدم ومجموعة خاصة للخدمة بأعلى درجات الأمان `memo-dashboard`.
6. تثبيت الملفات تحت مسار `/opt/memo-dashboard/releases` وعمل رابط رمزي لـ `/opt/memo-dashboard/current`.
7. إنشاء وضبط خدمة `systemd` تحت اسم `memo-dashboard.service` وتفعيل تشغيلها التلقائي عند إقلاع السيرفر.

---

### الخطوة 3: التحقق من حالة الخدمة

بعد انتهاء السكربت، تحقق من أن الخدمة تعمل بنجاح:

```bash
sudo systemctl status memo-dashboard
```

يجب أن تظهر الحالة: `Active: active (running)`.

للتحقق من السجلات الحية للخدمة:
```bash
sudo journalctl -u memo-dashboard -f
```

## 4. إعداد الاتصال بقاعدة البيانات وفحص الإصدارات (Database Setup & Version Verification)

### الخيار (أ): استيراد قاعدة البيانات الأساسية النظيفة (موصى به عند التثبيت لأول مرة)
إذا كنت تبدأ بقاعدة بيانات فارغة جديدة، يمكنك استيراد ملف `database_clean_master_data.sql` مباشرة عبر PostgreSQL:

```bash
# إنشاء قاعدة البيانات (إن لم تكن موجودة)
sudo -u postgres psql -c "CREATE DATABASE audit_memo WITH ENCODING 'UTF8';"

# استيراد البيانات الأساسية النظيفة (بدون مذكرات)
sudo -u postgres psql -d audit_memo -f database_clean_master_data.sql
```
تحتوي هذه النسخة على:
- كافة المخططات والجداول والفهارس والدوال.
- 9 شركات، 28 معملاً، 48 خط إنتاج، 4 أنواع مذكرات، 22 حقلاً ديناميكياً، 58 ربط حقول.
- 4 أدوار وصلاحيات، 8 مستخدمين أساسيين، إعدادات النظام وتقارير الهوية الرسمية.
- سجل الترحيلات محدّث بالكامل حتى الإصدار `069`.
- خالية 100% من أية مذكرات تجريبية أو بيانات سابقة.

---

### الخيار (ب): الربط بقاعدة بيانات حالية وفحص التوافق الذكي للإصدارات
عند تشغيل النظام لأول مرة أو تغيير إعدادات الاتصال:
1. افتح المتصفح وتوجه إلى عنوان السيرفر والمنفذ المحدد:
   ```
   http://<YOUR_SERVER_IP>:8080
   ```
2. في شاشة الدخول الأولى، اضغط على زر:
   **"ضبط إعدادات الاتصال بقاعدة البيانات"**
3. أدخل بيانات الاتصال بقاعدة بيانات PostgreSQL:
   - **الخادم (Host)**: اسم أو IP الخادم (مثال: `localhost` أو `127.0.0.1` أو عنوان سيرفر منفصل).
   - **المنفذ (Port)**: `5432` (أو المنفذ المخصص).
   - **اسم القاعدة (Database)**: `audit_memo`.
   - **اسم المستخدم (Username)**: مستخدم القاعدة (مثال: `postgres`).
   - **كلمة المرور (Password)**: كلمة المرور الخاصة بالمستخدم.
4. اضغط على **"اختبار الاتصال والحفظ"**:
   - يقوم النظام فوراً بفحص إصدار قاعدة البيانات ومقارنته بإصدار التطبيق (069):
     - **إذا كانت قاعدة البيانات متوافقة ومطابقة (الإصدار 069)**: يتم الحفظ وتفعيل النظام فوراً وبشكل طبيعي.
     - **إذا كانت قاعدة البيانات أقدم (تتطلب ترحيل)**: يُظهر النظام تنبيهاً واضحاً لمدير النظام مع خيار **"موافقة مدير النظام على ترحيل وتحديث قاعدة البيانات"**؛ ولا يتم تنفيذ أي ترحيل تلقائي صامت، بل ينتظر تأكيد مدير النظام لتطبيق الترحيلات المناسبة بأمان.
     - **إذا كانت قاعدة البيانات أحدث من الباك إند**: يتم حظر العملية تلقائياً لمنع تعارض البيانات وتظهر الرسالة الإلزامية:
       > *"يرجى مراجعة دائرة نظم وقواعد البيانات للتأكد من التحديث"*

## 5. إعداد جدار الحماية (UFW Firewall)

إذا كان جدار الحماية مفعلاً على الخادم، افتح المنفذ المستخدم:

```bash
sudo ufw allow 8080/tcp comment 'MemoDashboard Web Port'
sudo ufw reload
```

---

## 6. إعداد خادم Nginx العكسي مع شهادة SSL (موصى به للإنتاج)

لتشغيل المنظومة عبر النطاق الرسمي والمنفذ الافتراضي 80 / 443:

1. تثبيت Nginx:
   ```bash
   sudo apt install -y nginx
   ```
2. إنشاء ملف الإعداد في `/etc/nginx/sites-available/memo-dashboard`:
   ```nginx
   server {
       listen 80;
       server_name memo.company.local; # أو الـ IP الخاص بالسيرفر

       client_max_body_size 100M;

       location / {
           proxy_pass http://127.0.0.1:8080;
           proxy_http_version 1.1;
           proxy_set_header Upgrade $http_upgrade;
           proxy_set_header Connection keep-alive;
           proxy_set_header Host $host;
           proxy_cache_bypass $http_upgrade;
           proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
           proxy_set_header X-Forwarded-Proto $scheme;
       }
   }
   ```
3. تفعيل الموقع وإعادة تشغيل Nginx:
   ```bash
   sudo ln -s /etc/nginx/sites-available/memo-dashboard /etc/nginx/sites-enabled/
   sudo nginx -t && sudo systemctl reload nginx
   ```

## 7. الصيانة وإدارة الخدمة (Maintenance & Administration)

| الأمر | الوصف |
|---|---|
| `sudo systemctl restart memo-dashboard` | إعادة تشغيل خدمة لوحة البيانات |
| `sudo systemctl stop memo-dashboard` | إيقاف الخدمة مؤقتاً |
| `sudo systemctl start memo-dashboard` | بدء تشغيل الخدمة |
| `sudo journalctl -u memo-dashboard -n 100` | عرض آخر 100 سطر من سجلات الخدمة |
| `sudo journalctl -u memo-dashboard -f` | متابعة سجلات الخدمة مباشرة لحظة بلحظة |

---

## 8. الترقية من إصدارات سابقة (Upgrading)

للترقية من الإصدارات السابقة إلى 2.0.2:
1. فك ضغط حزمة `MemoDashboard-2.0.2-linux-x64.zip` في مجلد جديد.
2. تشغيل `sudo ./install.sh` بنفس مسار التثبيت السابق.
3. يقوم السكربت بعمل نسخة احتياطية من الإصدار الحالي وتحديث ملفات التشغيل دون مساس بالإعدادات أو قواعد البيانات.
4. بمجرد تشغيل الخدمة، ستقوم خدمة `DatabaseMigrationService` تلقائياً بتحديث أي ترحيلات جديدة على قاعدة البيانات.
