## أولاً: طريقة التثبيت على سيرفرات لينكس (Ubuntu Server 20.04 / 22.04 / 24.04 LTS)

### 1. نقل وفك ضغط الحزمة على السيرفر:
انقل الملف `MemoDashboard-2.0.2-linux-x64.zip` إلى السيرفر (عبر SSH أو فلاشة أو شبكة محلية)، ثم نفذ:

```bash
# إنشاء مجلد وفك الضغط
mkdir -p /tmp/memo-install
unzip MemoDashboard-2.0.2-linux-x64.zip -d /tmp/memo-install
cd /tmp/memo-install
```

### 2. تشغيل سكربت التنصيب التلقائي:
```bash
# إعطاء صلاحية التنفيذ
chmod +x install.sh

# تشغيل التنصيب وتحديد المنفذ والشبكة المسموحة
sudo ./install.sh --port 8080 --bind-address 0.0.0.0 --allowed-hosts "*"
```

### ماذا يفعل سكربت التنصيب تلقائياً؟
1. يتعرف على الحزمة كحزمة **مكتفية ذاتياً (Self-Contained)** ولا يحاول الاتصال بالإنترنت لتحميل أي بيئات برمجية.
2. ينشئ مستخدم نظام مخصص وآمن (`memo-dashboard`).
3. ينشئ مجلد النظام الرسمي في `/opt/memo-dashboard` مع إدارة الإصدارات والنسخ الاحتياطي.
4. يثبت خطوط "قمرة" العربية الرسمية في مستودع خطوط النظام (`/usr/share/fonts/truetype/qomra`).
5. ينشئ خدمة نظام قياسية (`systemd unit`) باسم `memo-dashboard.service` تضمن تشغيل المنظومة تلقائياً مع إقلاع السيرفر وإعادة تشغيلها عند أي طارئ.
6. يشغل الخدمة مباشرة ويتحقق من سلامتها.

### أوامر إدارة الخدمة على السيرفر:
* **فحص حالة الخدمة:** `sudo systemctl status memo-dashboard`
* **إعادة تشغيل الخدمة:** `sudo systemctl restart memo-dashboard`
* **إيقاف الخدمة:** `sudo systemctl stop memo-dashboard`
* **مشاهدة سجلات النظام المباشرة (Logs):** `sudo journalctl -u memo-dashboard -f`

## ثانياً: طريقة التشغيل والتثبيت على أنظمة ويندوز (Windows)

1. فك ضغط الملف **`MemoDashboard-2.0.2-win-x64.zip`** في أي مسار تفضله (مثال: `D:\MemoDashboard` أو `C:\MemoDashboard`).
2. افتح المجلد الناتج.
3. اضغط مرتين على ملف:
   👉 **`تشغيل_النظام.cmd`**
4. ستقوم المنظومة تلقائياً بتشغيل الخادم، وإطلاق المتصفح الافتراضي على الرابط:
   **`http://localhost:5000`**

*(ملاحظة: يمكنك مشاركة الرابط عبر الشبكة الداخلية للوصول إلى اللوحة من أي جهاز آخر في الشبكة عبر: `http://SERVER_IP:5000`)*.

## ثالثاً: ضبط الاتصال بقاعدة البيانات لأول مرة (PostgreSQL Setup)

عند فتح النظام لأول مرة في المتصفح:
1. ستظهر شاشة تسجيل الدخول وبجانبها زر **"إعدادات الاتصال" (أيقونة الترس ⚙️)**.
2. أدخل بيانات سيرفر الـ PostgreSQL المحلي أو الشبكي:
   * **عنوان السيرفر (Host):** `localhost` (أو عنوان IP السيرفر).
   * **المنفذ (Port):** `5432`.
   * **اسم قاعدة البيانات (Database):** `audit_memo`.
   * **اسم المستخدم (Username):** `postgres`.
   * **كلمة المرور (Password):** كلمة مرور قاعدة البيانات.
3. اضغط **"حفظ واختبار الاتصال"**.
4. **التحديث التلقائي المدمج:** سيقوم النظام تلقائياً بفحص قاعدة البيانات وتطبيق كافة الترحيلات الـ 70 حتى أحدث إصدار معتمد بدون أي تدخل يدوي.
